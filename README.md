A GitHub-compatible git forge written from scratch in Go: a single-process, single-threaded epoll server implementing git smart HTTP (upload-pack v2, receive-pack), the REST v3 API, GraphQL, and MCP, backed by its own in-memory object store with no external services and no git binary.

## Run it

```sh
node main.ts
```
